# Coco v0.1.0

**Initial signed release** — first version with automatic update support enabled.

このバージョン以降は、起動時に GitHub Releases を自動チェックして新版を取得します
(設定 → 更新 で OFF 可)。これより前の手動配布版を使っている場合は、本リリースを **一度だけ手動でダウンロード + 再インストール**してください。以降のバージョンは自動で配信されます。

## 主要機能

### スプレッドシート (Excel/Sheets 互換 70+ 機能)

**入力 / 編集**
- ピボットテーブル、テーブル(構造化参照)、スパークライン
- 関数挿入ウィザード (134 関数 / 9 カテゴリ)
- フラッシュフィル (Ctrl+E)、クイック分析 (Ctrl+Q)、ジャンプ / 名前ボックス (Ctrl+G)
- ハイパーリンク、スレッドコメント (返信・解決対応)、画像
- 記号 / シンボル挿入 (155 グリフ)、セルリンク挿入

**書式**
- セルスタイルギャラリー (Excel プリセット網羅)
- 罫線ダイアログ (12 プリセット)
- 数値書式マネージャ、表示形式の一覧管理
- 条件付き書式: 全種類対応 + 数式ベース + dataBar + colorScale + iconSet
- 条件付き書式: ルールの管理 + クイックプリセット

**データ**
- 並べ替え (基本 / 色) + フィルター (基本 / 詳細 / 色 / 値検索)
- 小計、重複の削除、区切り位置、データクリーニング
- データフォーム、データ検証、スマート日付認識
- 名前付き範囲、テーブル変換 (範囲 ⇄ テーブル)
- 範囲の比較、シナリオの管理、予測シート

**シート / ブック**
- シート非表示・再表示、移動 / コピー、見出し色
- グループ化 / アウトライン、シート保護
- 全シート検索置換 (Ctrl+Shift+H)
- カスタムリスト、計算オプション (Manual/Auto/F9)

**表示 / レビュー**
- ウォッチウィンドウ、依存関係トレース、コメント常時表示
- 数式の表示 (Ctrl+`)、エラーチェック / エラー一覧
- ブック統計、コメント / 画像 / ハイパーリンクの一覧管理
- ブックマーク (Ctrl+D)、シートメモ
- スナップショット履歴 + 差分比較、テンプレートギャラリー
- ドキュメント検査 (個人情報スクラブ)、スペルチェック

### ファイル入出力

- `.xlsx` / `.xlsm` ネイティブ対応 + `xl/cocoExtensions/*` で Coco 拡張データを保全
- `.coco` ローカル形式 (SQLite ベース、スナップショット内蔵)
- CSV インポートウィザード (4 段階プレビュー、文字コード自動判定)
- HTML / PDF / CSV エクスポート、ワークスペースバンドル (.zip)
- ピボット / スパークライン / テーブル / スライサー / シナリオなど全機能の xlsx round-trip
- 互換性警告 (Excel で開いた後、Coco 拡張データが失われた可能性を検出)

### 自動アップデート (新規)

- 起動時に GitHub Releases を匿名 HTTPS GET でチェック (既定 ON、設定で OFF 可)
- minisign 署名検証 + 改ざん耐性
- Markdown 形式のリリースノート表示
- 「このバージョンをスキップ」/「後で」対応
- 強制アップグレード (CVE 対応の `min_required_version` 機構)
- 段階的ロールアウト (10% → 100%、`FNV-1a(installationId)` バケット)
- ヘルプメニュー / 設定ダイアログから手動チェック可能

### セキュリティ

- VBA / 外部リンク / 埋め込みオブジェクト等の互換警告
- ハイパーリンクは `http(s)` / `mailto` / 内部参照のみ許可 (`file:` 拒否)
- CSV 注入対策 (=, +, -, @ 先頭エスケープ)
- 自動バックアップ 5 世代 + 整合性チェック (PRAGMA integrity_check)

## 既知の制限

- macOS / Linux 版は未提供 (Phase 3 で予定)
- Windows SmartScreen 警告 (EV コード署名証明書を導入していないため)
  → 「詳細情報」→「実行」で進めてください
- ベータチャネルトグルは UI のみ実装 (次回バージョンで配信先切替を有効化)
- 暗号化 / パスワード保護されたファイルは未対応

## システム要件

- Windows 10 / 11 (x86_64)
- ディスク 100 MB + ドキュメント保存先
- ネットワーク (自動アップデート OFF 時は完全オフライン動作可)

## インストール

- `Coco_0.1.0_x64-setup.exe` (NSIS、推奨): ダブルクリックでインストーラ起動
- `Coco_0.1.0_x64_en-US.msi`: 企業環境向け MSI パッケージ
- 個別: `coco.exe` を任意のフォルダに配置 (ポータブル動作)

検証用 SHA-256: `SHA256SUMS.txt` 参照
