# Coco v0.2.0

v0.1.0 からの主な変更点。UI を Excel ライクに刷新し、多数の機能拡張を追加しました。

## UI 刷新

- **スタートスクリーン**: ホーム画面を Excel 風に再設計 — 左サイドナビ、テンプレートタイルのインライン表示、最近使ったファイルの表形式表示 (#197)
- **リボン UI**: フラットなツールバーをタブ式リボンへ刷新（ホーム / 挿入 / 数式 / データ / 校閲 / 表示）。名前ボックス + 数式バーを常時表示 (#198)
- **ダークモード**: ライト / ダーク / システム追従の 3 モード。設定から切替 (#191)

## 機能拡張

- ステータスバーに選択範囲の集計表示（合計 / 平均 / 個数 ほか）(#192)
- 分析ツールパック拡充: t 検定 / カイ二乗検定 / 相関行列 / 乱数生成 / 移動平均 / FFT / 多元配置 ANOVA (#187)
- マクロ拡張: 編集可能 DSL / グローバルショートカット / 暗号化保存 (#186)
- スマートチップ: ユーザー定義の正規表現チップ (#185)
- フォームコントロール: ラジオボタン / スピンボタン / スクロールバー (#183)
- 図形: 矩形 / 円 / 矢印 + グループ化 (#188)
- カメラ機能: セル範囲のリンク画像 (#184)
- 外部データ連携: ETL ステップ / Web API / SQLite 接続 / スケジュール更新 (#190)
- スクリプト実行環境: トリガー (onOpen / onEdit) / iframe サンドボックス (#189)
- UrlFetch: 認証情報の永続化 / ストリーミング / WebSocket・SSE (#180, #181, #182)
- i18n: 関数名ローカライズ / 言語の即時切替 (#179)

## 修正・改善

- 外部ブック参照のキャッシュ値が xlsx 保存で失われる不具合を修正 (#176)
- ウィンドウ分割: xlsx を開いた直後に分割表示が反映されるよう改善 (#178)

## 既知の制限

- 3D 参照 (`Sheet1:Sheet3!A1`) は数式文字列の保全のみ。評価は Univer 0.5.x の制約により未対応 (#175)
- グラフ / 画像 / フォームコントロールのグリッド上描画は一部制約あり

## セキュリティ

- UrlFetch 系は allow list / SSRF ガードを全経路に適用
- 認証情報は OS セキュアストレージ (Windows Credential Manager 等) に保存

## システム要件

- Windows 10 / 11 (x86_64)

本バージョンより GitHub Releases 経由で自動アップデートを配信します。
