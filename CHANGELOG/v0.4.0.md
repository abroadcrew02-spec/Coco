# Coco v0.4.0

v0.3.0 からのマイナーアップデート。リボン UI を Excel に大きく寄せました。

## 変更点

- **リボンを Excel ライクに刷新** (#202)
  - フォント / 配置 / 数値ボタンをアイコンのみ表示にし、リボンが横スクロールせず通常ウィンドウ幅に収まるように
  - 画面上部の旧メニューバー（ファイル / 編集 / …）を撤去し、リボンに「ファイル」「ツール」タブを統合
  - フォント色 / 塗りつぶし色をカラーパレット、表示形式をメニューに — クリックで展開して選択するドロップダウンボタンを導入
- リボンのドロップダウンの不具合（トグルで閉じない / フォーカス / アクセシビリティ）を修正 (#203)

v0.3.0 までの全機能を含みます。
