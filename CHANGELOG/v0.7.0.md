# Coco v0.7.0

「最強Excel」ロードマップ (15 features) 完遂リリース。v0.6.1 以降の全機能をまとめて配信します。

## 新機能

### Power Pivot / Data Model (DAX エンジン)
- 17 個の DAX 関数 (SUM / AVERAGE / MIN / MAX / COUNT / COUNTROWS / DISTINCTCOUNT / IF / ALL / RELATED / SUMX / AVERAGEX / MINX / MAXX / COUNTX / FILTER / CALCULATE)
- メジャー / 計算列のオーサリング UI (MeasureListPanel / MeasureEditorDialog / CalculatedColumnEditorDialog)
- DAX オートコンプリート、関数シグネチャツールチップ、構文エラーのインライン表示
- メジャー間参照 (`[MeasureName]` 構文)、メジャー / 計算列のリネーム時に Pivot 参照を自動追従
- Excel テーブルをデータモデルに昇格、ライブプレビュー、関数 / 列参照チップ

### Pivot Table × DAX
- ピボットの値フィールドにメジャーを割り当て可能 (データモデルをソースにした per-cell 評価)
- 既存ピボットの編集 (PivotListPanel)

### Power Query 風 Get & Transform
- json / csv / sqlite / jsonl / tsv ソース取り込み
- 13 種類の変換ステップ (列選択 / 削除 / フィルター / ソート / グループ化 / 型変換 / 補完 / 条件列 / 置換 / 分割 / 結合 / インデックス)
- 保存済みクエリパネル (一覧 / 再実行 / 削除)

### In-grid Chart (自前描画)
- グリッド上にチャートをオーバーレイ描画 (6 種類: bar / line / pie / stacked / scatter ほか)
- ドラッグ移動 / ハンドルリサイズ / ダブルクリック編集 / Delete 削除
- **Coco 作成チャートを Excel が認識する OOXML として出力** (相互運用)

### In-grid Image
- グリッド上に画像をオーバーレイ描画、ドラッグ / リサイズ / 削除
- 前面・背面 (z-order) + 90° 回転
- xlsx ラウンドトリップ (import 正規化 + export 再生成)

### 条件付き書式 (CF) ライブ再描画
- sidecar 方式で安全なライブ再描画 (数値を壊さない iconSet グリフ表示)
- 矩形バッチ最適化、古いスナップショットからの数値リカバリ

### Linked Data Types (ローカル / serverless)
- ローカル CSV / SQLite をデータ型ソースとして登録、セル値でルックアップ → カード表示 / セル展開
- 複数キー一括ルックアップ、展開列の選択、Shift_JIS 自動検出、in-memory キャッシュ

### フォームコントロール
- Excel 由来コントロールの byte-preserve ラウンドトリップ
- Coco 作成の CheckBox / Radio / Spinner / ScrollBar を OOXML ネイティブ出力

### Slicer
- ピボット連動スライサー、一括操作ボタン (すべてクリア / すべて選択 / 反転)

### xlsx ラウンドトリップ拡張
- `xl/model` (Data Model) / `xl/queryTables` / `xl/ctrlProps` / `xl/embeddings` の保持

## 修正

- セキュリティ: chartRender の SVG 属性インジェクション対策 (色のエスケープ)
- CF iconSet: glyph 文字列で汚染されたスナップショットからの数値復元

## 自動アップデート

このバージョンより、Help → アップデート確認、および起動時自動チェックが有効です (設定で無効化可能)。
