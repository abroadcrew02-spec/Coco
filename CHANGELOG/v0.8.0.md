# Nicel v0.8.0

アプリ名を **Coco から Nicel に変更**したリリースです。v0.7.0 からの自動更新で配信されます。

## 変更

### 名称変更 (Coco → Nicel)
- ウィンドウタイトル・ホーム画面・ヘルプ・設定などアプリ内の表記をすべて Nicel に変更
- インストーラ名は `Nicel_0.8.0_x64-setup.exe` / `Nicel_0.8.0_x64_*.msi`、インストール先は `Nicel` フォルダ、実行ファイルは `nicel.exe`
- 自動更新でインストールする際、旧 `Coco` のインストール (アプリ本体・ショートカット・「アプリと機能」の項目) を自動で削除してから Nicel を配置し、スタートメニューとデスクトップに `Nicel` のショートカットを作り直します。設定・最近使ったファイル・復元候補・マクロなどのデータは保存場所が変わらないため、そのまま引き継がれます
- タスクバーにピン留めしていた `Coco` は更新時に外れます。更新後に `Nicel` を改めてピン留めしてください (自動では復元できません)
- スクリプト API の名前空間は `Nicel.*` (`Nicel.onOpen` / `Nicel.onEdit` / `Nicel.addMenuItem` / `Nicel.addTimer`)。旧名 `Coco.*` も同じオブジェクトを指すエイリアスとして残るため、保存済みスクリプトはそのまま動作します

### 互換性のため変更していないもの
- ワークブックの拡張子 `.coco` (既存ファイルはそのまま開けます)
- xlsx 内の Nicel 拡張パート (`xl/cocoExtensions/*.json`) と保存データのキー名
- 設定・データの保存場所 (`%AppData%\com.coco.app`)
- 自動更新の配信元と署名鍵

### チャート
- Excel 向け OOXML 出力で系列ごとの色とデータラベルを出力するようにし、空白セルを含む系列は空白をギャップとして出力 (#334)

## 既知の問題

- MSI でインストールした環境では、自動更新後も旧 Coco の項目が「アプリと機能」に残ることがあります。その場合は Coco を手動でアンインストールしてください (データは消えません)
- Nicel で作成したチャート / 画像 / フォームコントロールの Excel 上での見え方は、実 Excel での目視確認が未実施です (#337)
