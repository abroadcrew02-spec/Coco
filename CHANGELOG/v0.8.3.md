# Nicel v0.8.3

何も編集していないのに「未保存」扱いになり、自動更新が止まっていた問題を直したリリースです。v0.8.2 からの自動更新で配信されます。

## 修正

### 開いた直後は「未保存」にしない
- 新規ブックを作ったとき、xlsx / CSV を開いたときに、編集していなくても「未保存」と • が付いていた問題を修正。編集して初めて未保存になります
- Excel 由来の再計算や行の高さの自動調整など、Nicel 内部で起きる変更は編集扱いにしません
- 新規ブックの未編集状態は「新規ブック」と表示します (保存先が無いため「保存済み」とは出しません)

### 自動更新の確認
- v0.8.1 で入れた「未保存の変更があると更新を開始しない」動作をやめ、確認ダイアログ (続行 / キャンセル) に変えました。未保存の変更が無ければ何も聞かずに更新できます
- ダウンロード後の再起動も同様に、未保存の変更がある場合だけ確認します

## 既知の問題

- 前回の xlsx 保存より後に自動保存 (復元用) だけが動いている状態は、これまでどおり「未保存」です
